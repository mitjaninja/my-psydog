# CLAUDE.md

Проект: Telegram Mini App «тамагочи» для домашних заданий между сессиями с психологом. Источник истины — SPEC.md, продуктовый контекст — PRD (ссылка в README).

## Правила

- Работать по шагам SPEC.md строго по порядку; после шага — проверки из «Готово, когда», показать результат и остановиться до подтверждения. Ничего вне скоупа шага.
- Жёсткие продуктовые правила из раздела 0 SPEC.md не нарушать: персонаж не страдает от пропусков, нет стриков/очков/красного, тёплый тон на «ты», кнопка «Мне очень плохо» всегда на главном, никаких ФИО/телефона/email.
- UI-тексты — на русском, комментарии к решениям — на русском.
- Перед коммитом: pnpm typecheck && pnpm lint && pnpm format:check.
