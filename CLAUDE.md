# CLAUDE.md

Проект: Telegram Mini App «тамагочи» для домашних заданий между сессиями с психологом. Источник истины — SPEC.md, продуктовый контекст — PRD (ссылка в README).

## Правила

- Работать по шагам SPEC.md строго по порядку; после шага — проверки из «Готово, когда». Владелец разрешил идти по шагам без остановки на подтверждение: шаг на зелёных проверках вливается в main. Ничего вне скоупа шага.
- Жёсткие продуктовые правила из раздела 0 SPEC.md не нарушать: персонаж не страдает от пропусков, нет стриков/очков/красного, тёплый тон на «ты», кнопка «Мне очень плохо» всегда на главном, никаких ФИО/телефона/email.
- UI собирается на shadcn/ui (`apps/web/src/components/ui`, добавлять через `pnpm dlx shadcn@latest add <name>` из `apps/web`). Цвета — только токены shadcn, они привязаны к теме Telegram в `index.css`; свои hex-цвета — только для шкал потребностей и персонажа. `--destructive` намеренно нейтральный.
- UI-тексты — на русском, комментарии к решениям — на русском.
- Перед коммитом: pnpm typecheck && pnpm test && pnpm lint && pnpm format:check.
